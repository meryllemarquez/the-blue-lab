    Problems solved

    Strangers in the room

    Issue: a code alone is guessable. Solved: code plus password, registered accounts only, capped guesses.

    README, commit 79fe333

    Edit collisions

    Issue: two people edit one stop. Solved: the stale save gets a 409, not an overwrite.

    README, AGENTS.md rule 6

    Duplicate nicknames

    Issue: two members, one name. Solved: unique per gala, case-insensitive, enforced in the database.

    commits 30acd93, 654fb88

    Location privacy

    Issue: sharing where you are feels risky. Solved: off by default, gala members only, one-tap stop.

    components/gala/map/Location.tsx

    Photos in the backend

    Issue: uploads bloat the server. Solved: bytes go to Drive; the server keeps file ids only.

    README, commits 5fd3f78, d36d04c

    Tech and deployment

    Web

    Next.js 16, React 19, TypeScript, Tailwind CSS 4, TanStack Query, MapLibre, dnd-kit.

    Backend

    Java 21, Spring Boot 4, Flyway migrations, Redis cache that can fail safely.

    Data and auth

    Supabase Postgres, Auth and Realtime. JWTs verified by the backend. Photos on Google Drive.

    Mobile

    Expo app that ports the web screens.

    Hosting

    Web on Vercel. API on Railway (Docker). Live at otw.vinnn.app.

    Status

    2026. Student project. CI runs backend tests, a Docker build and web checks.

    Sample data only. Names, amounts and codes are made up. UI recreated from the OTW source.
