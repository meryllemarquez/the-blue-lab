      Key features

      • Today dashboard

        Total utang, low stock, top sellers and a weekly chart.

      • Quick sell

        Sell 1 on a favorite makes a cash sale with a receipt.

      • Store View cashier

        Tiles, sizes, cart, Other item, payment and live change.

      • Receipts log

        Every sale by date, with search and the full receipt.

      • Open and close the store

        Cash count with Short, Over or Balanced, plus closing history.

      • Utang ledger

        Customer balances, utang history and partial payments.

      • English and Filipino

        Every screen is available in both languages.

      Problems solved

      • Quick sell lowered stock but left no record of the sale.Every sale is a receipt and moves the expected cash.
      • A bad connection could save the same sale twice.Each sale has its own request id, so a retry saves once.
      • Selling more than the stock.The sale is refused, and the short lines are marked.
      • Forgotten or unchecked cash counts.Closing needs a count and a note when it is Short or Over.

      Tech and deployment

      Front end
      Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Inter font
      Data
      TanStack Query talking to a separate REST API
